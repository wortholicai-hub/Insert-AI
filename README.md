## ⚡ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Framework** | Astro 5 (Static + Islands) |
| **Styling** | Tailwind CSS 4 + Custom CSS |
| **3D Visuals** | Three.js (Crystal scene, neural network) |
| **Language** | TypeScript |
| **Deployment** | Vercel (Edge) |
| **Fonts** | Self-hosted variable fonts (Sora, Space Grotesk, Geist) |

## 🏗️ Architecture

```
src/
├── components/          # Astro components (all sections)
│   ├── Hero.astro       # Hero with 3D crystal + metrics
│   ├── Services.astro   # Case studies slider with portfolio images
│   ├── Integrations.astro # Service cards with scrolling tool tags
│   ├── IntegrationsWall.astro # Hub diagram with animated wires
│   ├── Vision.astro     # Astronaut visual + tags
│   ├── Results.astro    # Stats + social proof
│   ├── CrystalScene.astro # Three.js crystal renderer
│   ├── Nav.astro        # Floating glass navbar
│   ├── Footer.astro     # Footer + legal/guide modals
│   └── ...
├── data/                # Site config, logo groups
├── layouts/             # Base HTML layout + scroll reveal
└── styles/              # Global CSS + animations
```

## 🎨 Key Features

- **3D Crystal Hero** — Interactive Three.js crystal with neural network, lightning bolts, and scroll-driven animations
- **Portfolio Slider** — 8-category image slider with slide + blur + shimmer transitions, left/right navigation, and hover pause
- **Scroll Blur Reveal** — All content fades in with a blur-to-sharp effect as you scroll
- **Animated Integration Hub** — SVG wire diagram with comet animations connecting tool categories
- **Scrolling Tool Tags** — Tool marquees that activate on card hover with edge fade
- **Legal & Guide Modals** — Styled popup modals for Privacy Policy, Terms of Service, and Client Engagement Guide
- **Glass Morphism UI** — Frosted glass navbar, gradient cards, and ambient glow effects
- **Fully Responsive** — Optimized for all screen sizes with mobile-first breakpoints

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
